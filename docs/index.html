Summarize meeting notes on your own computer.

Local document summary turns pasted text into a draft summary using Ollama running on the same Windows computer. No hosted service or account is involved.

Download the prototype · v0.1.1 Read setup and privacy details

Try it locally

The release includes a fictional sample and setup instructions for Node.js and Ollama. The initial downloads, including the local model, need internet access.

Keep control of your notes

The app sends pasted text to the local Ollama API, binds to loopback, and does not save submitted documents. Review the output against the original before using it.

Know the limits

This prototype summarizes text only. It does not record audio, transcribe meetings, or connect to Teams or Meet. Summaries can omit or invent details.

Quick start

  1. On Windows, install Node.js 22 or later and Ollama.
  2. Start Ollama and download the model once with ollama pull qwen3.5:4b.
  3. Extract the release ZIP, run START.cmd, then open http://127.0.0.1:18891 on that computer.

Setup downloads require internet access. The running prototype uses the Ollama service on the same computer.
